# แดชบอร์ดการตลาดดิจิทัล — Metropolitan Products

เว็บแอปสำหรับทีมใช้งานร่วมกัน (หลายคนเข้าพร้อมกันได้ผ่าน URL เดียว) ทำหน้าที่ 4 อย่าง:

1. **กรอกข้อมูล** — เพิ่ม/แก้ไข/ลบข้อมูลรายเดือน (session, lead, ยอดขาย, ช่องทาง) และรายการค่าใช้จ่ายการตลาด **แยกตามปี** (แต่ละปีกำหนดรายการ/งบเองได้ เพราะต้นทุนมักเปลี่ยนทุกปี) กรอกทีละเดือน/ทีละรายการผ่านฟอร์มก็ได้ หรือดาวน์โหลด **Template CSV** ไปกรอกหลายเดือน/หลายรายการพร้อมกันใน Excel แล้วอัปโหลดกลับเข้าระบบทีเดียวก็ได้เช่นกัน
2. **แดชบอร์ด** — มี 2 มุมมอง สลับได้จากปุ่มด้านบน: **"มุมมองรายปี/ช่วงเวลา"** ดูกราฟและตัวเลขสรุปของช่วงเวลาที่เลือก และ **"เปรียบเทียบระหว่างปี"** ดูกราฟเทียบ session, lead, ยอดขาย, งบการตลาด, ROAS, ต้นทุนต่อ lead ของแต่ละปีข้างกัน
3. **ใบเสนอราคา** — อัปโหลดไฟล์ export ใบเสนอราคาดิบจากระบบ ERP (.xlsx หรือ .csv) แล้วระบบสรุปให้อัตโนมัติ: จำนวนใบเสนอราคารายเดือน, สัดส่วน/มูลค่าตามช่องทางที่มา (Line OA, แนะนำจากลูกค้าเดิม, Website ฯลฯ), สถานะใบเสนอราคา (ปิดการขายแล้ว/ไม่ได้/รอตัดสินใจ) และอัตราปิดการขาย นำเข้าไฟล์เดิมซ้ำได้เรื่อยๆ — ระบบจะอัปเดตสถานะของใบเสนอราคาที่เลขที่ซ้ำกันให้ล่าสุดเสมอ (ไม่สร้างซ้ำ) รายละเอียดคอลัมน์ที่ระบบต้องการ ดูหัวข้อ ["รูปแบบไฟล์ใบเสนอราคาที่นำเข้าได้"](#รูปแบบไฟล์ใบเสนอราคาที่นำเข้าได้) ด้านล่าง
4. **สไลด์สรุป** — สร้างไฟล์ `.pptx` สไตล์นำเสนอผู้บริหาร มี 2 โหมดให้เลือก: **"รายงานปกติ"** (11 หน้า) จากข้อมูลตามช่วงเวลาที่เลือกไว้ในแท็บแดชบอร์ด (รองรับทั้งข้อมูลปีเดียวและหลายปี) และ **"เปรียบเทียบปีต่อปี"** (6 หน้า) เลือกปีที่ต้องการโฟกัสแล้วระบบจะเทียบกับปีก่อนหน้าให้อัตโนมัติ โดยใช้เฉพาะช่วงเดือนที่มีข้อมูลตรงกันทั้งสองปี (เช่น ถ้าปีล่าสุดมีข้อมูลถึงแค่ ก.ค. จะเทียบแค่ ม.ค.–ก.ค. ของทั้งสองปี) เพื่อไม่ให้ปีที่ข้อมูลยังไม่ครบเสียเปรียบ (ยังไม่รวมข้อมูลใบเสนอราคาในสไลด์ชุดนี้)

ระบบเริ่มต้นแบบไม่มีข้อมูล (`data.json` ว่างเปล่า) — เข้าไปกรอกข้อมูลรายเดือนและรายการค่าใช้จ่ายเองทั้งหมดได้ในแท็บ "กรอกข้อมูล"

ในแท็บ "แดชบอร์ด" เลือกช่วงเวลาที่ต้องการดูได้ (เช่น ดูแค่ไตรมาสล่าสุด หรือทั้งหมดที่มี) ตัวเลขสรุปและกราฟจะคำนวณใหม่ตามช่วงที่เลือกทันที และปุ่มดาวน์โหลดสไลด์ในแท็บ "สไลด์สรุป" จะใช้ช่วงเวลาเดียวกันนี้ในการสร้างไฟล์ด้วย

**เรื่องค่าใช้จ่ายรายปี:** ก่อนตัวเลขต้นทุน/ROAS/ต้นทุนต่อ lead จะถูกต้อง ต้องกรอกรายการค่าใช้จ่ายของปีนั้นๆ ก่อนในแท็บ "กรอกข้อมูล" ช่อง "ค่าใช้จ่ายการตลาด" (เลือกปีจาก dropdown แล้วเพิ่มรายการ) ถ้าปีไหนยังไม่กรอก ระบบจะขึ้นแถบเตือนสีเหลืองในแดชบอร์ดให้ทราบ และคำนวณต้นทุนปีนั้นเป็น 0 ไปก่อน

**เรื่องการนำเข้าข้อมูลด้วย CSV:** ในแท็บ "กรอกข้อมูล" ทั้งส่วนข้อมูลรายเดือนและส่วนค่าใช้จ่ายมีกล่อง "เพิ่มข้อมูลด้วยไฟล์ CSV" ให้ดาวน์โหลด Template ว่าง (หรือดาวน์โหลดข้อมูลปัจจุบันมาแก้) เปิดกรอกใน Excel/Google Sheets ได้ตามสะดวก แล้วอัปโหลดไฟล์กลับเข้าระบบ:
- **ข้อมูลรายเดือน:** แถวที่ปี+เดือนซ้ำกับข้อมูลเดิมจะอัปเดตทับให้อัตโนมัติ เหมือนกรอกผ่านฟอร์มทีละเดือน ส่วนแถวใหม่จะถูกเพิ่มเข้าไป ไม่กระทบเดือนอื่นที่ไม่ได้อยู่ในไฟล์
- **ค่าใช้จ่าย:** ไฟล์มีคอลัมน์ "ปี" ในตัว จึงกรอกได้หลายปีพร้อมกันในไฟล์เดียว การนำเข้าจะ **แทนที่รายการทั้งหมดของปีที่ปรากฏในไฟล์** ด้วยข้อมูลในไฟล์นั้น ส่วนปีอื่นที่ไม่ได้อยู่ในไฟล์จะไม่ถูกแตะต้อง (ระบบจะถามยืนยันก่อนทุกครั้ง พร้อมสรุปว่าจะแทนที่ปีไหนบ้าง)
- ตัวเลข/เปอร์เซ็นต์ในไฟล์รองรับรูปแบบที่พิมพ์หรือคัดลอกจาก Excel ได้ตามธรรมชาติ เช่น "91%", "1,234,567.89", หรือ "-" แทนศูนย์ ระบบจะแปลงให้อัตโนมัติ
- ถ้าบางแถวในไฟล์กรอกไม่ครบหรือใส่ค่าที่แปลงเป็นตัวเลขไม่ได้ ระบบจะข้ามแถวนั้นและแจ้งเป็นข้อความเตือน ส่วนแถวที่ถูกต้องจะถูกบันทึกตามปกติ

## วิธีติดตั้งและรันครั้งแรก

ต้องมี [Node.js](https://nodejs.org) เวอร์ชัน 18 ขึ้นไป (ติดตั้งเครื่องไหนก็ได้ 1 เครื่องที่จะใช้เป็น "เซิร์ฟเวอร์กลาง")

```bash
cd marketing-dashboard
npm install       # โหลดไลบรารีที่จำเป็น (ใช้แค่ pptxgenjs ตัวเดียว ต้องมีอินเทอร์เน็ตตอนติดตั้ง)
npm start         # รันเซิร์ฟเวอร์
```

จะเห็นข้อความ `Marketing dashboard running: http://localhost:4173`

เปิดเบราว์เซอร์ไปที่ `http://localhost:4173` ก็ใช้งานได้ทันที

## ให้คนอื่นในทีมเข้าใช้งานพร้อมกัน

แอปนี้เป็นเซิร์ฟเวอร์ตัวเดียวที่เก็บข้อมูลไว้ในไฟล์ `data.json` — ทุกคนที่เข้าผ่าน URL เดียวกันจะเห็นข้อมูลชุดเดียวกันแบบเรียลไทม์ (รีเฟรชหน้าเพื่อดึงข้อมูลล่าสุด) มี 2 ทางเลือกหลัก:

**ทางเลือกที่ 1 — รันในเครื่อง/เซิร์ฟเวอร์บริษัท (ง่ายที่สุด ไม่มีค่าใช้จ่าย)**
รันแอปนี้บนคอมพิวเตอร์เครื่องหนึ่งที่เปิดทิ้งไว้และอยู่วง LAN เดียวกับทีม (เช่น เครื่อง server เล็กๆ ในออฟฟิศ) แล้วให้ทีมเข้าผ่าน IP เครื่องนั้น เช่น `http://192.168.1.50:4173` (ดู IP เครื่องด้วยคำสั่ง `ipconfig` บน Windows หรือ `ifconfig`/`ip addr` บน Mac/Linux)

**ทางเลือกที่ 2 — deploy ขึ้นโฮสติ้งฟรี (เข้าได้จากนอกออฟฟิศด้วย)**
บริการอย่าง [Render.com](https://render.com) หรือ [Railway.app](https://railway.app) มี free tier ที่รองรับแอป Node.js แบบนี้ได้ทันที ขั้นตอนคร่าวๆ:
1. อัปโหลดโฟลเดอร์นี้ขึ้น GitHub repository (private ก็ได้)
2. เชื่อม Render/Railway เข้ากับ repo นั้น ตั้ง Start Command เป็น `npm start`
3. ระบบจะให้ URL สาธารณะมา แชร์ลิงก์นั้นให้ทีมใช้ได้เลย

> **หมายเหตุด้านความปลอดภัย:** เวอร์ชันนี้ยังไม่มีระบบล็อกอิน เหมาะสำหรับใช้ภายในทีมที่ไว้ใจกันหรือจำกัดการเข้าถึงผ่านเครือข่ายบริษัท หากจะเปิดให้เข้าถึงจากอินเทอร์เน็ตทั่วไป ควรเพิ่มการยืนยันตัวตน (password/login) ก่อน — แจ้งได้หากต้องการให้เพิ่มส่วนนี้ให้

## รูปแบบไฟล์ใบเสนอราคาที่นำเข้าได้

แท็บ "ใบเสนอราคา" ออกแบบมาให้ใช้กับไฟล์ export ใบเสนอราคาดิบจากระบบ ERP ที่บริษัทใช้อยู่ตรงๆ (ไม่ต้องแก้ไฟล์ก่อนนำเข้า) ระบบจะอ่านคอลัมน์เหล่านี้จากไฟล์ (ชื่อคอลัมน์ต้องตรงตามนี้ในแถวหัวตาราง):

| คอลัมน์ในไฟล์ | ใช้ทำอะไร |
| --- | --- |
| `DocuNo` | เลขที่ใบเสนอราคา — ใช้เป็นรหัสอ้างอิงกันซ้ำตอนนำเข้าไฟล์เดิมซ้ำ |
| `DocuDate` | วันที่ออกใบเสนอราคา — ใช้หาเดือน/ปี |
| `SaleAreaName` | ช่องทางที่มาของใบเสนอราคา (เช่น Line OA, Website, Walkin) ถ้าว่างจะนับเป็น "Existing Customers (Not Use)" |
| `NetAmnt` | มูลค่าใบเสนอราคาสุทธิ (รวม VAT) |
| `QuotStatus` | สถานะ (เช่น "ปิดการขายแล้ว", "ปิดการขายไม่ได้", "รอลูกค้าตัดสินใจ") |

รองรับทั้งไฟล์ `.xlsx` (อ่านชีทแรกในไฟล์) และ `.csv` ที่มีหัวคอลัมน์ตรงตามด้านบน แถวที่ไม่มี `DocuNo` หรือวันที่อ่านไม่ได้จะถูกข้ามและแจ้งเตือนจำนวนแถวที่ข้าม โดยไม่กระทบแถวอื่น

**นำเข้าไฟล์เดิมซ้ำได้ทุกครั้งที่มีความเคลื่อนไหวใหม่** — ระบบอัปเดตข้อมูลตามเลขที่ใบเสนอราคา (`DocuNo`) ถ้าเลขที่ซ้ำกับที่มีอยู่แล้ว ข้อมูลจะถูกแทนที่ด้วยค่าล่าสุดในไฟล์ (เช่น สถานะเปลี่ยนจาก "รอลูกค้าตัดสินใจ" เป็น "ปิดการขายแล้ว") ถ้าเป็นเลขที่ใหม่จะถูกเพิ่มเข้าไป จึงสามารถ export ไฟล์สะสมทั้งหมดจาก ERP มานำเข้าซ้ำได้เรื่อยๆ โดยไม่ต้องกังวลเรื่องข้อมูลซ้ำซ้อน

## โครงสร้างไฟล์

```
marketing-dashboard/
├── server.js          เซิร์ฟเวอร์หลัก (ไม่ใช้ Express ใช้ Node.js built-in เท่านั้น)
├── calc.js             สูตรคำนวณตัวเลขทั้งหมด (ต้นทุนต่อ lead, ROAS, สัดส่วนออนไลน์, สรุปใบเสนอราคา ฯลฯ)
├── pptx-builder.js      ตัวสร้างไฟล์ .pptx (รายงานปกติ 11 หน้า + เปรียบเทียบปีต่อปี 6 หน้า)
├── xlsx-lite.js         ตัวอ่านไฟล์ .xlsx แบบไม่พึ่ง library ภายนอก (ใช้กับการนำเข้าใบเสนอราคา)
├── data.json            ที่เก็บข้อมูล (แก้ไขผ่านหน้าเว็บ ไม่ต้องแก้ไฟล์นี้ตรงๆ)
├── package.json
└── public/              หน้าเว็บ (HTML/CSS/JS ล้วน ไม่มี framework, มี csv.js ใช้ร่วมกับฝั่งเซิร์ฟเวอร์ด้วย)
```

## แก้ไข/ต่อยอด

- อยากเพิ่ม/ลดจำนวนรายการค่าใช้จ่าย: แก้ในแท็บ "กรอกข้อมูล" ได้เลย ไม่ต้องแตะโค้ด
- อยากเปลี่ยนดีไซน์สไลด์ (สี/เลย์เอาต์): แก้ที่ `pptx-builder.js`
- อยากเปลี่ยนตัวเลขที่คำนวณหรือเพิ่มสูตรใหม่: แก้ที่ `calc.js` (ทั้งแดชบอร์ดและสไลด์จะอัปเดตตามอัตโนมัติเพราะใช้ไฟล์เดียวกัน)
